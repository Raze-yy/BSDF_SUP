The integration uses the same sample–channel validity mask for the system and reference within 10° ≤ θ ≤ 70°, with cos(θ) dΩ weights. No normalization to a full hemisphere is applied. The reference azimuthal distribution is reconstructed from principal-plane scans under the normal-incidence rotational-symmetry approximation for diffuse samples.

The signed relative discrepancy in each row is 100 × (QCD, sys / QCD, ref − 1). Positive values indicate a larger system integral. The source permits this ratio only when |QCD, ref| > 10⁻¹²; all 64 rows meet that criterion. Signed system integrals, including negative low-signal estimates, are retained.

The signal-weighted absolute discrepancy for any group is E = 100 × Σ|QCD, sys − QCD, ref| / Σ|QCD, ref|. It is not the arithmetic mean of the signed row percentages.
